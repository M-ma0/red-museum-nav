# 我的观展笔记 · 正式上线手册

> 适用对象：公众号运营 / 网站管理员
> 目标：让 `自定义菜单 → 跳转网页` 能成功保存，并在微信内稳定打开本站
> 预估总成本：**首年 130–400 元**（取决于是否已有备案域名）
> 预估周期：**2–4 周**，其中 90% 是等 ICP 备案

---

## 一、先看懂你遇到的报错

截图里的报错是：

```
发布失败，链接内容不属于当前公众号
```

**这不是网络问题，也不是 GitHub Pages 不稳定，而是微信在保存菜单时校验"域名归属"。**

微信的规则是：自定义菜单里"跳转网页"的链接，其域名必须属于当前公众号 ——
判断依据是**公众号后台"功能设置"里登记过的域名**（业务域名 / JS接口安全域名 / 网页授权域名）。
`m-ma0.github.io` 从来不属于你的公众号，所以永远无法通过这个校验。

### 为什么 GitHub Pages 无法补救

| 微信要求 | github.io 的情况 |
|---|---|
| 域名需 **ICP 备案** | GitHub 是境外主体，个人无法为 `github.io` 备案 → 永远不满足 |
| 域名需能**上传校验文件到根目录** | 无权限控制，做不到 |
| 域名需属于公众号主体 | 不属于 |
| 境内访问稳定 | 境外服务器，国内时快时慢 |

**结论：必须换成"自己拥有 + 已备案 + 可控服务器"的域名。** 代码不用改，整站搬过去即可。

## 二、三档成本方案（先选方案再动手）

| | 方案 A（推荐） | 方案 B（最省钱） | 方案 C（不推荐） |
|---|---|---|---|
| 做法 | 腾讯云轻量服务器 + 新域名 + 备案，Nginx 托管 | **复用馆方已有备案域名**的子域名，站点放馆方已有服务器 | 腾讯云 COS/CloudBase 静态托管 |
| 首年成本 | **约 130–400 元** | **≈ 0 元**（只占馆方现有资源） | 约 60–120 元 + 仍需备案资源 |
| 备案 | 需新备案（5–20 工作日） | **通常无需新建**（主体已备案，子域名一般不单独备案） | 仍需备案资源 |
| 技术要求 | 会用 SSH + Nginx 基本操作 | 需能改 DNS、能传文件到馆方服务器 | 中等 |
| 适合 | 全新独立上线 | **馆方已有官网/服务器** | 已有备案资源、想免运维 |

### 判断该走哪条路（5 分钟）

先回答一个问题：**馆方是否已有可用的备案域名和服务器？**

- **有** → 走**方案 B**，成本几乎为零：
  让馆方的网站管理员加一条 DNS 记录（如 `yunjian.馆方域名.com`），
  把本站文件放到该服务器的一个目录，配一个 Nginx `server` 块即可。
  **注意：备案主体必须与公众号主体一致**（单位对单位、个人对个人），否则微信会驳回域名配置。

- **没有** → 走**方案 A**，全新买一套，最省心。

> 以下步骤按**方案 A** 展开。方案 B 只需做"步骤 4 部署 + 步骤 5 公众号配置"，跳过买域名/备案。

## 四、执行步骤

### 步骤 1：购买域名并实名认证

1. 打开腾讯云 → 域名注册 → 搜索心仪域名
2. 建议选 `.cn` 或 `.com`，尽量短、好记、与主题相关，例如：
   - `hongsemuseum.cn`
   - `yunjian100.com`
   - 或与馆名缩写相关
3. 下单后进入 **域名控制台 → 实名认证**，上传主体证件
   - **务必用与公众号一致的主体**（单位公众号就用单位证件）
4. 等实名通过（1–3 天，通常几小时）

> ⚠️ 不要用 `.top`/`.xyz`/`.cc` 等小众后缀做正式站点，部分场景兼容性差、信任度低。

### 步骤 2：购买轻量应用服务器

1. 腾讯云 → 轻量应用服务器 → 新建
2. 地域：选**离你近的**（如上海/北京/广州）
3. 镜像：**Ubuntu 22.04 LTS** 或 **Debian 12**（干净、好装 Nginx）
4. 套餐：入门型 2核2G 即可（本站是纯静态，配置要求极低）
5. 购买时长：**1 年**（满足备案要求）
6. 购买后记录：**公网 IP**、root 密码（或绑定 SSH 密钥）
7. 在 **轻量 → 防火墙** 放行：`22`（SSH）、`80`（HTTP）、`443`（HTTPS）

### 步骤 3：提交 ICP 备案（关键步骤）

入口：腾讯云 → 备案 → 首次备案（或"新增网站备案"）

**逐字段填写建议**（可直接抄）：

| 备案项 | 建议填写 |
|---|---|
| 备案类型 | 新增网站（主体已备案则选"新增网站"） |
| 主体性质 | 按公众号主体选择：事业单位 / 企业 / 个人 |
| 主体证件 | 与公众号主体一致的证件 |
| 网站名称 | **我的观展笔记** |
| 网站域名 | 你买的域名（如 `hongsemuseum.cn`） |
| 网站服务内容 | 文化教育 / 公益宣传 |
| 前置审批 | 无 |
| 是否涉及新闻/出版/视听 | **否**（本站只做外链跳转，不转载内容） |
| 网站简介 | 汇集全国 15 家革命类博物馆、纪念馆的 40 个线上展馆入口，提供全景展馆、数字展馆等公开链接的导航服务，不提供用户注册、交互及内容发布功能 |
| 负责人 | 与主体一致，手机号需能接收核验短信 |

**备案注意事项：**

- 网站名称**不要**用纯地名、纯行业词，避开"中国""中央""国家"等敏感词
- 备案期间腾讯云会核验网站内容 → **先把站点部署好、内容齐全**，避免被要求整改
- 备案通过后拿到 **ICP 备案号**（如 `豫ICP备2026xxxxxx号`），建议展示在页脚
- 收到管局短信后**必须在 24 小时内完成核验**，否则会被退回

### 步骤 4：部署站点

#### 4.1 上传部署包

在项目里执行（会生成 `deploy/red-museum-nav-site.zip`，约 2.8 MB）：

```powershell
powershell -ExecutionPolicy Bypass -File deploy\打包.ps1
```

上传到服务器：

```bash
# 在本地执行（Windows 可用 scp 或 WinSCP/宝塔面板）
scp deploy/red-museum-nav-site.zip root@<你的服务器IP>:/root/
```

登录服务器并解压：

```bash
ssh root@<你的服务器IP>

mkdir -p /var/www/red-museum-nav
cd /var/www/red-museum-nav
unzip -o /root/red-museum-nav-site.zip

# 权限交给 Nginx 运行用户
chown -R www-data:www-data /var/www/red-museum-nav
ls -la          # 应看到 index.html / go.html / 404.html / assets / data / images
```

#### 4.2 安装并配置 Nginx

```bash
apt update && apt install -y nginx

# 把 deploy/nginx.conf 传上去，或直接新建
nano /etc/nginx/conf.d/red-museum-nav.conf
```

把 `deploy/nginx.conf` 的内容粘进去，并修改三处：

| 占位 | 改成 |
|---|---|
| `yunjian.example.com` | 你的真实域名（共 2 处：http 与 https 的 server） |
| `/etc/nginx/ssl/yunjian.example.com.pem` / `.key` | 你的证书路径 |
| `root /var/www/red-museum-nav;` | 若目录不同则改 |

校验并重载：

```bash
nginx -t && systemctl reload nginx
```

#### 4.3 配置 HTTPS（免费）

**方式一：腾讯云免费证书（推荐，省心）**

腾讯云 → SSL 证书 → 申请免费证书（DV）→ 绑定域名 → 校验 DNS →
下载 **Nginx 版**证书，上传到 `/etc/nginx/ssl/`，文件名对上 nginx 配置即可。
有效期一般 1 年。

**方式二：Let's Encrypt 自动续期**

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
systemctl list-timers | grep certbot   # 确认自动续期已启用
```

> ⚠️ 微信要求**必须 HTTPS**。校验文件若只能通过 HTTP 访问，微信会拒绝保存。

#### 4.4 自测

浏览器依次访问，都应正常：

- `https://你的域名/` → 导航首页
- `https://你的域名/go.html?e=e31` → 跳转页
- `https://你的域名/images/thumbs/e02.jpg` → 预览图
- `https://你的域名/不存在的页面` → 自定义 404 页

### 步骤 5：公众号后台配置域名（解决你的报错）

路径：**微信公众平台 → 设置与开发 → 公众号设置 → 功能设置**

三个字段建议填**同一个域名**：

#### 5.1 业务域名（解决菜单报错的关键）

1. 点「业务域名」右侧 **设置**
2. 填 `你的域名`（**不要**带 `https://`，不要带路径）
3. 页面会给出一个校验文件，文件名类似 `MP_verify_AbCdEf1234.txt`，内容是一串字符
4. **创建该文件并上传到网站根目录**：

```bash
# 在服务器上
cd /var/www/red-museum-nav
echo -n '直接把页面上的校验码粘在这里' > MP_verify_AbCdEf1234.txt
chmod 644 MP_verify_AbCdEf1234.txt
```

> `echo -n` 不要换行；Nginx 配置里已为根目录 `.txt` 单独放行（见 `deploy/nginx.conf`）。

5. **先自测再保存**：

```bash
curl https://你的域名/MP_verify_AbCdEf1234.txt
# 必须原样输出那串校验码，不能返回 HTML、不能 404、不能跳转
```

6. 回到公众平台点 **保存**

#### 5.2 JS接口安全域名

同样填 `你的域名`，同样需要把对应校验文件放到根目录。
本站**没有使用** JS-SDK（无 `wx.config`），但配了更保险，也便于以后加自定义分享。

#### 5.3 网页授权域名

如无微信登录需求可不配。本站不需要（纯静态展示，无用户体系）。

> 配置保存后**立即生效**，无需等审核。若显示未生效，强制关闭微信再试。

### 步骤 6：配置自定义菜单

回到 **自定义菜单** 页面：

| 字段 | 填写 | 注意 |
|---|---|---|
| 名称 | `云上观展` | **最多 4 个汉字或 8 个字母**。截图里的 `720浏览` 是 5 个字符，**超限了**，建议改掉 |
| 消息类型 | ✅ 跳转网页 | |
| 网页链接 | `https://你的域名/` | 必须是 **https**，域名必须是步骤 5 里登记过的 |

保存成功后，可继续加子菜单（每个名称同样 ≤4 汉字）：

| 菜单名 | 链接 | 落地位置 |
|---|---|---|
| 全景漫游 | `https://你的域名/#era0` | 党的诞生分组 |
| 星火燎原 | `https://你的域名/#era1` | 苏区岁月分组 |
| 长征转折 | `https://你的域名/#era2` | 伟大转折分组 |
| 延安十三年 | `https://你的域名/#era3` | 宝塔山下分组 |
| 进京赶考 | `https://你的域名/#era4` | 西柏坡分组 |
| 香山奠基 | `https://你的域名/#era5` | 为新中国奠基分组 |
| 强军征程 | `https://你的域名/#era6` | 军事专题分组 |

> 锚点由页面自动生成，只对**有入口的分组**存在，可直接使用。

> 名称超限是另一个独立坑：即使域名配好了，名称超过 4 汉字也保存不了。截图里 `720浏览` 需改成如 `全景浏览`（4 字）。

## 五、常见坑（按出现频率）

| 现象 | 原因 | 解决 |
|---|---|---|
| `链接内容不属于当前公众号` | 域名未备案或未在"业务域名"登记 | 完成步骤 3 + 5.1 |
| 保存业务域名失败 | 校验文件不在根目录 / 只能 HTTP 访问 / 返回了 HTML | `curl` 自测，确保返回纯文本；确认已开 HTTPS |
| 菜单名称存不了 | 超过 4 汉字或 8 字母 | 改名，如 `全景浏览` |
| 微信内白屏 | 链接是 `http://` | 全部用 `https://` |
| 微信内提示"无法确认页面安全性" | 业务域名没保存成功 | 重新保存并强杀微信重开 |
| 改完文件刷新没变化 | 浏览器/Nginx 缓存 | HTML 已设 no-cache；图片缓存 30 天，改名即可 |
| 备案被驳回 | 网站名称含敏感词 / 内容与主体不符 / 备案主体与公众号不一致 | 按本文表格修改后重提 |
