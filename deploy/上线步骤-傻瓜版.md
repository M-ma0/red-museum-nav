# 上线全流程 · 傻瓜版（照着做就行）

> 目标：让公众号菜单能保存成功，并在微信里稳定打开本站
> 总花费：**首年约 130–400 元**（不含可选的微信认证 300 元/年）
> 总耗时：**2–4 周**，其中 90% 时间在等 ICP 备案，实际动手约 3 小时
>
> 阅读方式：**从上到下按顺序做**，每一步都有【在哪点】【填什么】【怎么算成功】。
> 做完一步再进下一步，不要跳。

---

## 开始之前：先确认 3 件事（5 分钟）

| 要确认的 | 为什么重要 | 怎么查 |
|---|---|---|
| ① 公众号是**单位**还是**个人**主体 | 备案主体必须与公众号主体一致，否则微信驳回 | 公众平台 → 设置与开发 → 账号信息 → 主体信息 |
| ② 公众号是否**已认证** | 未认证可能看不到"业务域名"入口 | 同上，看"认证状态" |
| ③ 名下是否已有**备案域名** | 有的话可以省掉 1–2 周和几百元 | 问馆方技术/网管 |
### 根据结果选路线

```
公众号主体 = 单位（博物馆/纪念馆/事业单位/公司）
        │
        ├── 馆方已有备案域名和服务器？
        │        ├── 有 → 【捷径】只做「阶段 D + E」，让别人加个二级域名，成本≈0
        │        └── 没有 → 按本文「阶段 A→B→C→D→E」全部做完
        │
公众号主体 = 个人
        │
        └── 按「阶段 A→B→C→D→E」做，但注意：
             · 个人备案对网站名称限制更严，建议名称用「我的观展笔记」（已按个人备案规则改好）
             · 个人订阅号**不支持微信认证**；如果后台"功能设置"里没有「业务域名」，
               这条路走不通，需改用**单位主体**的公众号
```

> ⚠️ **最容易被卡住的一条**：备案主体、域名实名主体、公众号主体，三者必须一致。
> 单位公众号就用单位证件备案，不要图省事用个人身份证备案，后面 100% 会被驳回。

# 阶段 A：买域名（约 10 分钟 + 等实名 1–3 天）

## A1. 注册腾讯云账号并实名

【在哪】<https://cloud.tencent.com> → 右上角「注册」→ 微信扫码登录

【做什么】
1. 登录后按提示完成**实名认证**
   - 单位：选「企业实名」，上传**事业单位法人证书**或**营业执照**
   - 个人：选「个人实名」，上传身份证
2. 实名审核通常 10 分钟–2 小时

【怎么算成功】右上角头像 → 账号信息，显示「已实名」，且类型与你选的一致。

---

## A2. 买域名

【在哪】<https://console.cloud.tencent.com/domain> → 「域名注册」→ 搜索框输入想要的域名

【填什么】建议直接用这些命名方向搜索，挑没被注册的：

| 推荐后缀 | 例子 |
|---|---|
| `.cn` | `hongsemuseum.cn`、`yunjian100.cn` |
| `.com` | `hongsemuseum.com` |

【操作】
1. 加入购物车 → 结算 → 时长选 **1 年**
2. 勾选「**自动续费**」（防止到期被抢注）
3. 支付

【怎么算成功】域名控制台「我的域名」里能看到该域名，状态为「正常」。

> ❌ 不要用 `.top` / `.xyz` / `.cc` / `.tk` 这类后缀：备案和微信都容易出问题。
> ❌ 不要在域名里用拼音缩写到看不懂，比如 `hsbwgy.cn`，后续备案填写容易写错。

---

## A3. 域名实名认证（必做，否则无法备案）

【在哪】域名控制台 → 点进域名 → 「实名认证」

【填什么】上传与**腾讯云账号实名主体一致**的证件（单位证书 / 身份证）

【怎么算成功】域名列表里「实名认证」列显示 **已实名**。
通常几小时到 1–3 天，**必须等它通过才能备案**。

# 阶段 B：买服务器（约 10 分钟）

## B1. 购买轻量应用服务器

【在哪】<https://cloud.tencent.com/product/lighthouse> → 「立即购买」

【填什么】按下表逐一选择：

| 选项 | 选什么 |
|---|---|
| 地域 | 选离你近的：**上海 / 北京 / 广州**（必须**中国内地**，不能选香港或海外，海外无法备案） |
| 镜像 | **Ubuntu Server 22.04 LTS**（干净、命令通用） |
| 套餐 | 入门型 **2核2G / 40GB SSD / 2Mbps** 即可（本站是纯静态站，再低也够） |
| 购买时长 | **1 年** |
| 自动续费 | 建议勾选 |
| 数量 | 1 台 |

【关键检查】
- ✅ 必须是**包年包月**（不能选"按量计费"，按量计费无法用于备案）
- ✅ **购买时长 ≥ 3 个月**，且备案期间剩余有效期 **≥ 1 个月**（选 1 年最省事）
- ✅ 必须包含**独立公网 IP**

【怎么算成功】
付费后在 <https://console.cloud.tencent.com/lighthouse> 能看到实例，状态「运行中」，
记下 **公网 IP**（形如 `129.xxx.xxx.xxx`）。

## B2. 放行端口

【在哪】轻量控制台 → 点实例 → 「防火墙」

【填什么】确认有以下规则（没有就「添加规则」）：

| 应用类型 | 协议 | 端口 | 来源 |
|---|---|---|---|
| SSH | TCP | 22 | 全部 |
| HTTP | TCP | 80 | 全部 |
| HTTPS | TCP | 443 | 全部 |

【怎么算成功】三条规则都在列表里。

## B3. 拿到 root 密码

【在哪】轻量控制台 → 实例详情 → 「重置密码」或「登录」

【做什么】设置一个**记得住的 root 密码**（字母+数字+符号），记在安全的地方。

【怎么算成功】用 SSH 能登进去：
```bash
ssh root@你的公网IP
# 输入密码，出现 root@VM-...:~# 就是成功
```
Windows 可用 PowerShell 直接执行上面的命令。

# 阶段 C：ICP 备案（最耗时，**建议第一天就提交**）

> 备案期间网站**不能对外开放访问**，但你可以先部署好文件（阶段 D），审核通过后再放开。

## C1. 进入备案系统

【在哪】<https://console.cloud.tencent.com/beian> → 「开始备案」

【选择】

- 系统会让你选「备案云服务」→ 选刚买的**轻量应用服务器实例**

> ✅ **不需要"备案授权码"**。授权码只有企业账号能生成，用途是把备案资格授权给**别的账号**。
> 你自己用自己的服务器备案，直接选实例即可。

## C2. 填写主体信息

| 主体负责人 | 法定代表人 / 单位负责人 | 本人 |

| 通信地址 | 与证件地址一致（或实际办公地址） | 同 |

# 阶段 D：部署站点（备案审核期间就能做，约 40 分钟）

## D1. 本地打包

【在哪】在你电脑上，项目目录 `red-museum-nav` 里打开 PowerShell

【执行】
```powershell
powershell -ExecutionPolicy Bypass -File deploy\打包.ps1
```

【怎么算成功】生成 `deploy\red-museum-nav-site.zip`，约 2.8 MB，提示"打包完成"。

## D2. 上传到服务器

【执行】（把 `你的IP` 换掉）
```powershell
scp deploy\red-museum-nav-site.zip root@你的IP:/root/
```
提示输入密码时，输入 B3 设置的 root 密码。

【怎么算成功】传输进度到 100%，没有报错。

## D3. 一键部署（推荐，自动完成 Nginx + HTTPS 配置）

把 `deploy\server-setup.sh` 也传上去：
```powershell
scp deploy\server-setup.sh root@你的IP:/root/
```

然后登录服务器执行：
```bash
ssh root@你的IP

# 参数：你的域名  你的邮箱（证书到期提醒用）
bash /root/server-setup.sh hongsemuseum.cn you@example.com
```

脚本会自动完成：
1. 安装 Nginx
2. 解压站点到 `/var/www/red-museum-nav`
3. 写入带域名的 Nginx 配置（含微信校验文件放行、gzip、缓存）
4. 用 Let's Encrypt 申请免费 HTTPS 证书（自动续期）
5. 跑一遍自检并打印结果

【怎么算成功】脚本最后打印 `✅ 部署完成`，并给出可访问的网址。

> 如果脚本某步失败，看它打印的提示；也可以按 D4 手工做。

## D4. 手工部署（脚本失败时的备用方案）

```bash
# 1) 装 Nginx
apt update && apt install -y nginx

# 2) 解压站点
mkdir -p /var/www/red-museum-nav
cd /var/www/red-museum-nav
unzip -o /root/red-museum-nav-site.zip
chown -R www-data:www-data /var/www/red-museum-nav

# 3) 写 Nginx 配置（把域名替换成你的）
nano /etc/nginx/conf.d/red-museum-nav.conf
#   把 deploy/nginx.conf 内容粘进去，改 server_name 与证书路径

# 4) 校验并重载
nginx -t && systemctl reload nginx

# 5) 申请免费证书
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

## D5. 先做一次"上线前自检"（此时还不能公网访问）

```bash
# 在服务器上本地访问，验证站点是否正常
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1/
# 期望输出 200

curl -s http://127.0.0.1/ | grep -o "我的观展笔记"
# 期望输出 我的观展笔记
```

# 阶段 E：公众号配置（备案通过后，约 30 分钟）

## E1. 配置「业务域名」——这一步解决你的报错

【在哪】微信公众平台 → 设置与开发 → 公众号设置 → **功能设置** → 「业务域名」→ 设置

【填什么】只填域名，**不带 `https://`、不带路径**：
```

```

【操作】
1. 提交后页面给出一串校验内容，文件名形如 `MP_verify_AbCdEf1234.txt`
2. 登录服务器，**把这个文件放到网站根目录**：

```bash

ls MP_verify_AbCdEf1234.txt     # 确认文件存在
```

3. **先自测，再回后台保存**（顺序不能反）：

```bash
curl https://你的域名/MP_verify_AbCdEf1234.txt
```

必须**原样输出那串校验码**。如果返回 HTML、404 或跳转，都不要点保存。

【怎么算成功】业务域名列表里出现你的域名，没有红色报错。

# 卡住了怎么办：按现象查

| 现象 | 原因 | 解决 |
|---|---|---|
| 备案系统提示"没有可用云服务" | 服务器是**按量计费**或**剩余不足 3 个月** | 改成包年包月、时长 ≥ 3 个月 |
| 备案被驳回："网站名称不规范" | 名称含敏感词/纯地名/纯行业 | 改成「我的观展笔记」重提 |
| 备案被驳回："主体与域名不一致" | 域名实名主体 ≠ 备案主体 | 做域名过户，或换主体一致的域名 |
| 备案卡在"短信核验" | 超过 24 小时未核验 | 重新提交，注意及时核验 |
| 域名打不开、无响应 | 备案未通过（内地服务器会阻断） | 等备案；期间用服务器本地 `curl` 验证 |
| `https` 打不开但 `http` 可以 | 证书没申请成功 | 重跑 `certbot --nginx -d 域名`，确认 80 端口放行 |
| 微信后台保存业务域名失败 | 校验文件访问不到 / 返回了 HTML | `curl` 自测，确保返回纯文本；确认是 https |
| 菜单仍提示"链接不属于当前公众号" | 域名未加进业务域名，或用了别的域名 | 检查 E1，确认链接域名与登记域名完全一致（含 www） |
| 微信打开白屏 | 链接是 `http://` | 全部改 `https://` |
| 页面改了看不到更新 | 缓存 | 强制刷新；图片缓存 30 天，改名即可 |
| 找不到"业务域名"入口 | 公众号未认证 | 微信认证只对**企业/组织**主体开放，个人订阅号无法认证 → 需改用单位主体的公众号（或已认证账号） |

| 阶段 | 耗时 | 能否并行 |
|---|---|---|
